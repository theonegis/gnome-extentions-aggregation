# 验证记录

日期：2026-09-16。Fedora 44，GNOME Shell/Mutter 50.4，Wayland。

## 静态与打包检查

- `glib-compile-schemas --strict --dry-run schemas` 通过。
- `gjs -m tests/geometry.test.js` 通过：半开边界、负坐标、屏幕间空隙、
  上下排列、空屏幕列表、逻辑缩放尺寸和整数中心计算。
- `node --check extension.js` 和 `node --check prefs.js` 通过。
- `gnome-extensions pack` 及 `unzip -t` 通过。

## 隔离 Shell 实际运行

使用独立 session bus、XDG 数据目录及 `GSETTINGS_BACKEND=keyfile`，
创建 1280×720 和 1024×768 两块虚拟显示器。通过仅在临时测试目录内的
辅助扩展开放 Eval，注入虚拟键盘进行测试。该辅助代码不包含在发布包中。

通过项：

- 左右排列：右移到 `(1792,384)`，左移回 `(640,360)`。
- 上下排列：下移到 `(512,1104)`，上移回 `(640,360)`。
- 对应方向没有屏幕时，位置不变。
- 真实虚拟键盘事件 Super+Alt+Right 触发移动。
- 将快捷键即时改为 Super+Ctrl+Right 后，新组合触发移动。
- 清空快捷键后，原组合不再移动指针。
- 禁用后快捷键不再移动；重新启用后恢复。
- 修改虚拟显示器排列后无需重载扩展。
- GTK/libadwaita 设置窗口实际打开并截图检查。
- 点击快捷键按钮，弹出录制窗口，实际按 Super+Ctrl+L，保存为
  `<Control><Super>l`；之后恢复默认值。

发现 GNOME 默认快捷键冲突后，增加了设置页冲突提示及“释放冲突组合”按钮。
运行测试在临时设置中释放这些组合后通过。没有修改当前桌面的方向快捷键。

## 测试隔离问题及恢复

早期测试中，隔离 session bus 的 dconf 服务继承了真实用户的数据目录，
导致真实用户的 enabled-extensions 设置被测试列表覆盖。当前桌面仍保留原有
10 个已启用扩展，因此读取其运行状态恢复了启用列表；随后改用独立 keyfile
设置后端并在启动 D-Bus 之前设置 XDG 变量。测试辅助扩展未安装到真实用户目录。

## 范围限制

已验证虚拟双屏的 GNOME 50.4 行为，尚未在用户实际物理多屏桌面启用该扩展。
负坐标和缩放尺寸有纯函数测试，但未在物理混合 DPI 设备上实测。
锁屏不在快捷键允许的 action modes 中，未进行实际锁屏输入测试。
